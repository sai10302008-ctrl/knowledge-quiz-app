# Knowledge Quiz App

A mobile knowledge quiz app built with React Native and Expo.

## Features
- Multiple-choice questions
- Score tracking
- Animated dark ninja-themed background
- Results screen with restart option
- Mobile-friendly layout

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Run on Android/iOS simulator or scan the Expo QR code.

## Notes
This app uses a custom dark anime-inspired visual design to match your requested aesthetic.
